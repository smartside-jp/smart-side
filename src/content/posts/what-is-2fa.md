## 1行で答えると

2段階認証(英語で 2FA・ツーエフエー)は、<mark>**ログインの時にパスワード以外にもう1つの確認をする仕組み**</mark> のこと。

> <mark class="hi-pink">**【家のドアを2重ロックする】**</mark>のと同じ発想。

## 身近な例えで言うと

家のドアを思い浮かべてみる。

普通のドア → **鍵が1つ**
入念な家のドア → **鍵が2つ(下の鍵 + 上のチェーン)**

鍵を1個盗まれても、もう1個ロックがあれば中に入れない。

ネット上のアカウントも同じで、**パスワード(1つ目の鍵)を盗まれても、2つ目の確認**があれば乗っ取られない。これが 2段階認証。

## 3つの特徴(これだけ覚えておけば動ける)

### ① パスワードだけじゃ守れない時代になった

昔は **複雑なパスワード**さえ作れば安全だった。
でも今は違う。

- 大手サービスからパスワードが流出する事件が **年に何度も** ある
- 1つのパスワードを使い回してると、<span class="text-red">**他のサービスも全部やられる**</span>
- フリー WiFi 経由で盗まれる事故もある

→ パスワードを **見られても、もう1つの壁** で止められる仕組みが必要になった。それが 2段階認証。

### ② スマホで 6桁コード(これが一番多い形式)

2段階認証の代表的な形式：

1. **メールにコードが届く** → 一番簡単・でも安全度はやや低い
2. **SMS(電話番号)にコードが届く** → 簡単・でも電話番号系の事故あり
3. **Authenticator アプリで6桁コードを生成** → <span class="text-blue">一番おすすめ・安全度高い</span>
4. **指紋・顔認証** → 便利だけど読み取りエラーあり
5. **物理キー(YubiKey など)** → 最強だけどハードル高い

メイン口座やメールのような **大事なところ**は、3 の Authenticator アプリ式 にしておくのが一番安心。

### ③ 乗っ取られても、その場で止められる

2段階認証を入れていれば、知らない場所からのログイン試行があっても、**6桁コードを入力できないと中に入れない**。

サービスによっては、**「○○からログイン試行がありました」** とメールで通知が来る。
これが届いた時点で、「**自分は試してないのに通知が来た = パスワードがどこかから漏れてる**」と気づける。

つまり 2段階認証は<mark>**「侵入を防ぐ + 侵入の試みを察知する」の両方**</mark>をやってくれる。

## どこで使われているか

- **メイン メール**(Gmail・iCloud・Outlook):一番優先して入れるべき
- **銀行・証券会社・クレジットカード**:お金が動く場所
- **SNS・クラウド**(X・Instagram・Google Drive・iCloud):プライバシー守る
- **会社のシステム**:ほぼ全部 2段階認証 必須化されつつある

「**メイン メール**」から入れるのが基本。理由は、他のサービスのパスワード再発行通知が全部そこに届くから。

## 混同しやすい用語との違い

### パスワードマネージャーとの違い

パスワードマネージャー = **パスワードを安全に保管・自動入力する** 道具。
2段階認証 = **パスワードに加えて、もう1段階の確認をする** 仕組み。

両方を組み合わせるのが、最低限のセキュリティ構成。

→ [パスワードマネージャーって何?](/posts/what-is-password-manager/)

### Authenticator アプリとの違い

Authenticator アプリ = **2段階認証を実現する道具のひとつ**。

Google Authenticator や Microsoft Authenticator、1Password などがある。
6桁のコードを30秒ごとに生成する。

「2段階認証」 = 仕組み全体。
「Authenticator」 = その仕組みを動かす道具の1つ。

### TOTP との違い

TOTP(ティーオーティーピー) = Authenticator アプリで使われている **コード生成の方式**。
正式には Time-based One-Time Password。

「30秒ごとに6桁のコードが変わる」のが TOTP の正体。

ユーザーは「TOTP」という名前を知らなくてもまったく問題ない。Authenticator アプリを使ってれば、自動的に TOTP を使ってる。

## まとめ

2段階認証 = ログインに2つ目の確認を加える仕組み。

- パスワードだけじゃ守れない時代になった
- スマホで 6桁コード(Authenticator)が一番おすすめ
- 乗っ取られても、その場で止められる

この3つだけ覚えておけば、最初に何を守るべきか見えてくる。

<div style="text-align:center; font-size:1.3em; margin:1.5em 0;">
<mark class="hi-pink">**【まず メイン メール、次に お金周り】**</mark>
</div>

の順で入れていくのが王道です。
